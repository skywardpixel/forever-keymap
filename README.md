# Forever Keymap

Plan your WoW Forever action bars and keybindings before launch: pick a class and race, drag abilities onto the bars, bind keys with Quick Bind (hover + press, mouse buttons and wheel included), and check the result on the keyboard view.

```sh
npm install
npm run dev      # http://localhost:5173
npm test
npm run build    # static site in dist/
npm run data     # refresh ability data + icons from talentsforever.com
```
